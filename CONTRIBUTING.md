# Правила работы команды

## Участники и ответственность

- [@runessaa](https://github.com/runessaa) отвечает за обработку медиа, распознавание речи и субтитры.
- [@PokachalovaKseniya](https://github.com/PokachalovaKseniya) отвечает за интерфейс Gradio, интеграцию и тестирование.
- Приоритеты и оценки согласуем вместе. У каждой задачи один исполнитель, второй участник проверяет результат.

## Планирование

Работаем недельными спринтами. В начале недели выбираем задачи и согласуем их оценки. В конце недели показываем результаты и проводим ретроспективу.
Задачи и их статусы ведём в GitHub Issues и Projects. Решения по задаче записываем в её обсуждении.

## Ветки и коммиты

Для каждой работы создаём отдельную ветку от main. Название ветки описывает изменение, например docs/project-rules.
Каждый коммит содержит одно понятное изменение. В сообщении указываем, что сделано.

## Pull request

Изменения переносим в main через pull request. В описании пишем, что изменено и как проверить результат. Если работа связана с issue, указываем Closes #номер.
Второй участник проверяет изменения. После исправления замечаний и одобрения объединяем ветки.

## Определение готовности

Задача завершена, когда:
1. Получен результат, указанный в задаче.
2. Выполнена описанная в задаче проверка; для нового поведения программы добавлены необходимые тесты и они проходят.
3. Второй участник проверил и одобрил pull request.
4. Изменения объединены с main.
5. Связанные документы обновлены, если изменение на них влияет.
6. Задача закрыта и находится в колонке «Готово».
