# Разработка средств автоматического создания субтитров

Программное средство для автоматического создания субтитров из аудио- и видеоматериалов. Оно должно распознавать речь, формировать текст с временными метками и сохранять субтитры в форматах `.srt` и `.vtt`.

Проект предназначен для пользователей, которым нужно подготовить субтитры к учебным материалам, видеопубликациям и другим аудиовизуальным записям.

### Планируется

- Загрузка аудио- и видеофайлов через веб-интерфейс.
- Извлечение аудиодорожки из видео.
- Автоматическое распознавание речи с использованием *(В разработке)* через библиотеку *(В разработке)*.
- Формирование субтитров с временными метками и синхронизацией с исходным материалом.
- Экспорт готовых субтитров в форматы `.srt` и `.vtt`.
- Веб-интерфейс на основе Gradio для загрузки исходных файлов и получения результатов.
