# Разработка средств автоматического создания субтитров

Программное средство с веб-интерфейсом для автоматического создания субтитров из аудио- и видеоматериалов. Цель проекта - распознавать речь, формировать текст с временными метками и сохранять результат в распространённых форматах субтитров `.srt` и `.vtt`.

Проект предназначен для пользователей, которым нужны субтитры для образовательных материалов, публикаций в СМИ, видео для социальных сетей и других аудиовизуальных материалов.
