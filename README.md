# Разработка средств автоматического создания субтитров

Учебный проект программного средства, которое создаёт субтитры к аудио- и видеоматериалам с русской речью. Планируемый результат - текст с временными метками и отдельные файлы `.srt` и `.vtt`.

Проект предназначен для подготовки субтитров к учебным материалам, видеопубликациям и другим записям. Пользовательский интерфейс планируется реализовать на Gradio.

### Планируется в первой версии

- Загрузка одного аудио- или видеофайла.
- Подготовка аудио и автоматическое распознавание русской речи с GigaAM-v3.
- Формирование сегментов субтитров с временными метками.
- Отображение состояния обработки и ошибок.
- Просмотр и ручное исправление текста и времени сегментов.
- Скачивание отдельных файлов SRT и VTT.

Наложение субтитров на видео предлагается реализовать следующим этапом. Регистрация и личный кабинет в первой версии не предполагаются.

## Быстрый старт

```bash
git clone https://github.com/runessaa/Auto-subtitles.git
cd Auto-subtitles
```

Команда запуска приложения будет добавлена после появления проверенного прототипа.

## Требования

- **Язык программирования:** Python 3.10.
- **Распознавание речи:** GigaAM-v3.
- **Работа с ML-моделями:** `transformers`, `huggingface_hub`.
- **Обработка аудио:** `librosa`, `scipy`, `pydub`.
- **Обработка видео:** `moviepy`.
- **Веб-интерфейс:** `gradio`.
